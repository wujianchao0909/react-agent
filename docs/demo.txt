# 电气工程核心知识库文档
## 一、基础概念体系
1. 电压：静电物或电路中两点间的电位差，符号U，基本单位V，导出单位kV、mV，1kV=1000V，1V=1000mV。我国电压等级划分：低压380/220V，中压10/20/35kV，高压110/220kV，超高压500kV及以上。
2. 电流：电荷定向移动形成的物理量，符号I，基本单位A，导出单位kA、mA，1kA=1000A，1A=1000mA。人体允许自行摆脱电源的极限电流为30mA。
3. 电阻：导体对电流的阻碍作用，符号R，单位欧姆Ω，阻值与材料、横截面积、长度相关，横截面积越大电阻越小，导体越长电阻越大。
4. 欧姆定律：电路基本定律，部分电路形式I=U/R，表明直流纯电阻电路中电流与电压成正比、与电阻成反比。
5. 功率体系：有功功率P（单位W）、无功功率Q（单位Var）、视在功率S（单位VA），三者满足S²=P²+Q²，功率因数cosφ=P/S，交流电路有功功率计算公式P=√3UIcosφ。
6. 电路分析：电气工程基础分支，涵盖直流电路分析、动态电路时域分析、正弦稳态电路相量分析三大核心模块，核心理论包括基尔霍夫定律、叠加定理、戴维南定理、诺顿定理。

## 二、核心设备与元件
1. 变压器：基于电磁感应原理实现交流电压升降的电气设备，广泛应用于电力传输与配电环节。
2. 断路器：可在过载、短路工况下自动切断电路，实现电路保护与人员安全防护。
3. 继电器：电控开关装置，通过小电流控制大电流通断，在自动化控制、远程操作场景大量应用。
4. 电机类：包含旋转电机、发电电动机、外转子电动机等品类，对应GB/T 47501-2026《旋转电机 安全技术规范》等最新标准。
5. 光伏组件：对应GB 47739-2026《光伏组件安全要求》、GB 47740-2026《光伏组件铭牌标识要求》，2027年6月1日正式实施。

## 三、现行核心国家标准
1. GB 19517-2023《国家电气设备安全技术规范》：2024年6月1日实施，覆盖交流1000V、直流1500V以下电气设备的共性安全要求，是电气设备设计、制造的法规性依据。
2. 2026年新发布强制性国标：包含智能网联汽车辅助驾驶安全、电动自行车充电桩安全、电气火灾监控系统等15部标准，覆盖新能源、消防、能效等重点领域。
3. 2025年实施推荐性国标：涵盖高压交流断路器、110kV交联聚乙烯电力电缆、电动汽车充电机电能计量等27项电气设备类标准，全面更新行业技术要求。

## 四、工控自动化术语
1. 闭环控制：被控输出反馈至输入端，通过反馈机制修正控制量，是工业控制系统最主流的控制模式。
2. I/O点：控制系统输入/输出点位，I代表从仪表采集的测量参数，O代表向执行机构输出的控制参量，控制系统规模常以最大支持I/O点数量衡量。
3. 模拟量与开关量：模拟量是0-100℃温度、0-10MPa压力等连续变化的数值，通常需8-16位二进制表示；开关量仅包含通/断两种状态，1位二进制即可完成标识。
